# 关键 AI 提问与排障对话记录

大纲鼓励合理使用 AI 工具，并要求把**关键提问与排障对话**留痕。面试第 3 项「个人实践阅历与自主学习力」会看这里。

## 记录规范

每次有实质收获的对话存一份 `YYYY-MM-DD_主题.md`，包含：

```
## 场景
（当时卡在哪一步、想解决什么问题）

## 我的提问
（原样贴 prompt，包括描述得不好的地方，别美化）

## AI 给的方案
（关键结论 / 代码片段）

## 我怎么验证的
（跑了什么命令、结果是什么、哪里不对）

## 最后的取舍
（采纳了什么、否掉了什么、为什么）
```

## 建议至少留下的几类记录

- [ ] Phyphox 导出 CSV 后字段重命名 / 采样率确认
- [ ] FFT 特征提取脚本的首版与报错排查
- [ ] 盲测集划分与准确率异常时的定位过程
- [ ] 加噪后误判增多时的特征选择讨论

> 重点不是「用了 AI」，而是**你能不能讲清楚为什么采纳、怎么验证、哪里推翻了它**。只贴成功结果反而不可信。
