# 第一阶段：基础素养实地测评（10 选 2 · 20 分）

**硬门槛（两题都适用）**：本校实地采样原始数据表 `raw_data/` + **本人现场同框照片**。缺一项即失分。

## 课题 05：校园公共设施人机工程缺陷调研

- **采样**：实地找 3 处设计反直觉或效率低的设施，现场测关键几何尺寸 / 高度 / 操作耗时。
- **交付**：实测尺寸图 + 照片 + 百元预算内的结构或智能感应改造草图。
- **原始记录**：`raw_data/task05/measurement_log.csv`
- **照片**：`photos/task05_A1.jpg` … `task05_C3.jpg`（人在画面内，能看出正在测量）
- **报告**：`task05_report.md`

填写示例：

| id | date | time | location | facility | issue_type | dimension_cm | operation_time_s | photo_file |
|---|---|---|---|---|---|---|---|---|
| A1 | 2026-11-14 | 10:30 | 教学楼一楼东门 | 门把手 | 推拉方向反直觉 | 95 | 3.2 | task05_A1.jpg |

**报告建议结构**：① 现场与测量方法 ② 三处缺陷的实测数据 ③ 为什么算「缺陷」（观察/计时证据，别只写主观感受）④ 改造草图与百元预算清单 ⑤ 局限与未验证假设。

## 课题 08：多姿态步态加速度特征采集与对比

- **采样**：Phyphox（免费）采集平地慢走 / 快跑 / 上下楼梯 / 静止 4 种状态的三轴加速度。
- **交付**：4 份原始 CSV 波形文件 + 可视化图 + 区分动作的阈值规则。
- **原始数据**：`raw_data/task08/gait_walk.csv`、`gait_run.csv`、`gait_stairs.csv`、`gait_still.csv`
- **照片**：`photos/task08_stairs.jpg`（楼梯间本人同框）
- **报告**：`task08_report.md`

**采集约定**（写进报告，面试会追问）：

| 项目 | 约定 |
|---|---|
| 工具 | Phyphox「加速度（不含 g）」，采样率 50 Hz（或设备默认值，如实记录） |
| 手机位置 | 全程固定在右裤袋 / 手持贴身，四种状态一致 |
| 单次时长 | 每状态连续 20–30 秒，静止作为基线 |
| 文件字段 | `time_s, acc_x, acc_y, acc_z`（Phyphox 导出后统一重命名） |
| 边界记录 | 机型、采样率、当天地面状况、是否换鞋，写入 `raw_data/task08/sampling_notes.md` |

**阈值规则怎么出**：对每份 CSV 算三轴合加速度的均值 / 标准差 / 峰值，画折线对比，给出形如「合加速度标准差 > X 判为跑，< Y 判为静止」的判别式，再用留出的一段数据自查准确率。脚本可放 `../02-20Days-Challenge/src/` 复用。
