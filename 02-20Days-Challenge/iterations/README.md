# 迭代记录模板

至少 3 次**有实际 diff** 的提交，每次复制下面这份填一份 `iter01.md` / `iter02.md` / `iter03.md`。

## iterXX：一句话标题

- 日期 / commit hash：
- **看到了什么**（引用具体日志或数据文件，别写「效果不好」这种空话）：
- **判断的原因**：
- **改了什么**（列出改动文件与关键 diff）：
- **结果变化**（改前 → 改后的准确率 / 误判数，附数据）：
- **还没解决的问题**：

> 要求：每次迭代都能在 `process_logs/` 的当日记录里找到对应依据。被推翻的尝试保留，不要删。

## 参考节奏

| 迭代 | 触发点 | 可能的改动方向 |
|---|---|---|
| iter01 | 初版阈值在「高档」与「失衡」间误判 | 引入谱质心 / 谐波能量特征 |
| iter02 | 加背景噪声后准确率明显下降 | 增加带通滤波或改用抗噪特征 |
| iter03 | 发现两组离群数据 | 核查手机距离不一致，补录并在采样说明中标注 |
