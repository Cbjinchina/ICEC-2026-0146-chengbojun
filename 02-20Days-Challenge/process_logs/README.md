# process_logs 日志规范

本目录是第二阶段「跨多日连续过程数据」的证据区，**评分和面试都从这里取材料**。

## 目录

```
process_logs/
├── raw/                  75 组原始 WAV/CSV + sampling_notes.md
├── photos/               各工况实验照
├── blind_test.mp4        盲测准确率视频
├── run_log_YYYY-MM-DD.md 每日运行/采集记录
└── README.md             本文件
```

## 每日记录模板（`run_log_YYYY-MM-DD.md`）

```
## 2026-11-__ 第 __ 天
- 今天做了：采集 / 写脚本 / 调参 / 补录
- 产出文件：（列出新增文件名）
- 遇到的问题：
- 怎么定位的：
- 结论与下一步：
- commit：（写本次提交 hash 前 7 位）
```

## 硬性约定

- 每天至少一次 commit，且当天日志与 commit 内容对得上。
- 不批量补写历史日志；日志按真实时间逐日追加。
- 运行日志含脱敏时间戳、调用频次、耗时、报错记录（若脚本有自动记日志功能，直接落盘到本目录）。
- 原始文件不删不改；修正以新文件 + 说明进行。
