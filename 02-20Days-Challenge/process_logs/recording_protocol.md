# 音频采集操作手册（项目三 · 手机声振诊断仪）

> 采集人：程博钧 ｜ 设备：Redmi K70 至尊版（2407FRK8EC）｜ 日期：2026-11-18
> 目标：5 种工况 × 15 组 = 75 段，每段 10 秒；**录音机只需按 5 次**

---

## 0. 一句话流程

**摆好位置 → 每个工况按一次录音、录 3 分钟 → 换工况 → 共 5 次 → 拷文件。**

3 分钟的连续录音由脚本自动切成 15 段 10 秒，不需要你手动分段、也不需要录 15 次。

---

## 1. 录前准备（5 分钟，做错全废）

### 1.1 几何关系（最关键）

```
    ┌──────────┐
    │  电风扇   │  ← 全程不移动
    └──────────┘
         ↕ 30 cm（尺子量，误差 ≤1 cm）
    ┌──────────┐
    │  手机      │  ← 平放桌面，充电口（麦克风）朝风扇
    └──────────┘
```

- 手机**平放桌面**，不要手持；充电口那一头朝向风扇
- 用**两本书或两支笔**夹住手机左右两侧做定位，每次放回都抵住
- 用书或重物**抵住风扇底座后方**，防止贴配重后振动移位
- 手机离墙 ≥30 cm，避免墙面反射

### 1.2 环境

- 关窗、关空调；关灯（部分灯具镇流器有嗡声）
- 手机开**飞行模式**（避免来电震动）
- **笔记本合上或搬走**——它的风扇声会混进来
- 请室友把声音压一压（15 分钟即可），打游戏的戴耳机

### 1.3 格式

录音机 → 设置 → 录音格式：有 **WAV** 选 WAV，否则用 **M4A**（音质「高」）。

> **本次实测配置：M4A（AAC，48 kHz 立体声，128 kbps）**，转码后统一为 16-bit 单声道 WAV，链路已验证。
> **须写入报告「局限性」**：M4A 为有损压缩，会削弱高频细节与低电平成分；被测噪声主能量在 2 kHz 以下，对判别无实质影响。

### 1.4 试录（只做一次，20 秒）

录 20 秒回放：不能有破音、发「炸」的感觉。已实测本机在 30 cm 处峰值 −6.8 dBFS、无削波，可直接开录。

## 2. 六次录音（核心，约 25 分钟）

**每条都录 3 分钟**（180 秒）。操作完全一样：

```
点 ● 开始 → 放好手机别动 → 等 3 分钟 → 点 ■ 停止 → 自动保存
```

| 第几次 | 工况 | 档位 | 额外动作 |
|---|---|---|---|
| **1** | c01 低档正常 | **1 档** | 无 |
| **2** | c02 高档正常 | **4 档** | 无 |
| **3** | c03 扇叶失衡 | **2 档** | 扇叶贴配重（见 §3.2） |
| **4** | c02b 中档正常 | **2 档** | **先撕掉配重**再录（c03 的配对基线） |
| **5** | c04 进气受阻 | **1 档** | 纸板挡后网罩约一半 |

> **2026-11-22 现场修订（三）**：第 6 条"叠加背景噪声"取消现场录制，改为**离线叠加**（`src/add_noise.py`）。理由：现场放白噪声只能得到一个固定的信噪比，且音量无法标定；而在已录的干净样本上按 20/15/10/5/0 dB 多档混入高斯白噪声，可得到**准确率-信噪比曲线**，既更严谨，又不必占用现场时间。报告中须注明"抗噪测试采用离线合成噪声，非现场实录"，列为局限。

> **2026-11-22 现场修订（二）**：第 3、4 条顺序互换——配重已贴好，先录失衡态，再拆配重录正常态。配对关系不变（同为 2 档），仅录制先后调换，不影响单变量对照。

> **2026-11-22 现场修订**：原方案 c03 用 4 档，实测该小风扇扇叶仅数克，4 档加配重后整机在桌面位移、无法稳定运行。改为 **2 档**（离心力随转速平方下降，2 档幅度适中且机身可控）。因更换了转速，**必须补录一条 2 档正常基线**，否则 c03 与 c01（1 档）的差异会与"转速不同"混淆——故录音总数由 5 条增至 **6 条**。

**顺序绝不能乱**——脚本按文件时间戳分组，顺序错则工况归属全错。

**每录完一条，先停 5 秒再动风扇**，让录音机把文件写完。

## 3. 五种工况定义

| 编号 | 工况 | 说明 |
|---|---|---|
| c01 | 正常 · 低档 | 基线 1 |
| c02 | 正常 · 高档 | 基线 2 |
| c03 | 扇叶失衡 | 转子不平衡 |
| c04 | 进气受阻 | 风路受阻 |
| c05 | 叠加背景噪声 | 信噪比下降 |

### 3.1 实验设计：单变量对照

五个工况构成**三组受控对照**：

| 对照组 | 唯一变化的因素 |
|---|---|
| c01（1 档正常） vs **c04**（1 档 + 遮挡） | 进气条件 |
| c02b（2 档正常） vs **c03**（2 档 + 配重） | 转子平衡 |
| c02（4 档正常） vs **c05**（4 档 + 噪声） | 信噪比 |

每组只变一个因素，因此特征差异可**归因到该因素**，而非"转速不同"。这就是为什么每个工况都要有**同档位**的正常基线——若 c03 用 2 档却拿 1 档做基线，配重与转速两个因素就纠缠在一起，无法归因。**此设计须写入报告方法章节。**

### 3.2 c03 配重（材料：双面胶）

1. **拔电源**，逆时针旋转前网罩取下（转约 1 cm 位移；拆不下就停手，改 §3.3）
2. 剪 **1cm×1cm 硬纸板**，叠 **3~4 层**粘牢
3. 双面胶贴在**一片扇叶背面**，位置**距叶尖约 1/3**，不得超出叶边
4. 装回网罩，**手动转一圈**确认不蹭网罩
5. 通电 **2 档**试转 10 秒：
   - 规律「嗡—嗡—」起伏、机身明显抖但**不位移** → **合适**
   - 抖到风扇在桌上乱跑 / 有「哒哒」撞击声 → **太重**，撕一层
   - 几乎听不出变化 → **太轻**，加一层

> ⚠ **不要用硬币配重**。扇叶单片约 3~5 g，一枚 5 角硬币 3.8 g 接近 100% 不平衡量，会甩坏扇叶。**目标 1~2 g**。

### 3.3 拆不下网罩时的替代（c03′）

底座一侧垫 2~3 层折纸使机身微倾约 2°，同样产生周期性不平衡。**须在采样记录与报告中注明替代原因**，故障类型写"安装不平衡（机身倾斜）"，不可写成"转子不平衡"。

### 3.4 c04 遮挡

用硬纸板挡住**后网罩**约 1/2 面积（挡进风侧比挡出风侧安全）。3 分钟内每隔 1 分钟摸一次电机外壳，**明显发烫立即停止并改用 30 秒短录**。

```bash
cd C:/Users/chengbojun/WorkBuddy/2026-11-13-22-47-24/cbj-/02-20Days-Challenge
python src/ingest_audio.py --input "D:/icec/raw_audio" --output process_logs/raw
```

## 附录 A · c03 配重后机身不稳的处理（2026-11-22 现场追加）

| 现象 | 判断 | 处理 |
|---|---|---|
| 机身原地抖动、可听到"嗡—嗡—"规律起伏 | **这就是要的故障特征**，属正常 | 不动配重，继续录 |
| 风扇在桌面上位移（走动） | 配重过大 | 减重：撕掉 1~2 层纸板，或把面积由 1cm² 缩到 0.5cm² |
| 有"哒哒"撞击声 | 配重蹭到网罩 → 变成摩擦声，数据无效 | 断电，剪小配重或贴得更贴近叶面，手转一圈确认不蹭 |
| 减重后仍有位移 | 底座摩擦不足 | 底座下垫折叠毛巾或防滑垫 + 后方抵书，不改变风扇朝向 |
| 以上均不成立 | 机型扇叶过轻 | 改用 **c03′**：不拆机、不加配重，底座一侧垫 2~3 层折纸使机身微倾约 2°，故障类型记为"安装不平衡（机身倾斜）" |

**原则**：配重只需"可测量的差异"，不需要"明显的抖"。c03 与 c02b 同为 **2 档**，只改变转子平衡一个变量；若因故再换档位，必须同步补录同档位的正常基线，并在采样记录中注明，否则对比失去意义。
