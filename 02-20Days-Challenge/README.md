# 项目三：基于手机内置传感器的日常旋转机械 / 电器异常声振诊断仪

**材料**：个人手机（麦克风 + 加速度计）+ 电风扇 / 吹风机 + 胶带。不用借设备、不用焊接、不用连续多天挂机。

## 必交三项对照（20 / 20 / 20）

| 评审项 | 分值 | 本仓库对应位置 | 状态 |
|---|---|---|---|
| ① 5 种工况 × 15 组原始 WAV/CSV 序列及实验照 | 20 | `process_logs/raw/` + `process_logs/photos/` | 待采集 |
| ② 时域 / 频域特征提取代码 | 20 | `src/fft_features.py` + `src/classify.py` | 待编写 |
| ③ 盲测准确率视频与抗噪报告 | 20 | `process_logs/blind_test.mp4` + `noise_robustness.md` | 待录制 |

## 5 种工况定义

| 编号 | 工况 | 具体做法 | 预期可区分特征 |
|---|---|---|---|
| cond01 | 正常 · 低档 | 风扇低档稳定运行 | 基频低、幅值小 |
| cond02 | 正常 · 高档 | 风扇高档稳定运行 | 基频升高、幅值增大 |
| cond03 | 扇叶轻微失衡 | 单片扇叶贴一小段胶带 | 转频及其谐波幅值上升 |
| cond04 | 进出风口遮挡 | 用纸板半挡进风口 | 宽带噪声 / 气流声变化 |
| cond05 | 叠加背景噪声 | 在 cond02 基础上播放人声或环境噪声 | 检验抗噪能力 |

> 工况不必照抄，但若改动，请在 `process_logs/raw/sampling_notes.md` 写清改动理由与新的边界条件。

## 文件命名与采样约定

- 音频：`cond01_run01.wav` … `cond05_run15.wav`，共 **75 个**文件。
- 同步加速度（可选但加分）：同名 `.csv`，字段 `time_s, acc_x, acc_y, acc_z`。
- 每段连续录 **10 秒**；同一工况内手机位置、距离、朝向保持不变。
- 采样率、机型、麦克风距离、胶带位置等全部写进 `process_logs/raw/sampling_notes.md`。
- 实验照：每种工况至少 1 张，能看到设备、手机摆放、异常设置（如胶带）。

## 分析链路

1. `src/fft_features.py`：读 WAV → 分帧 → `numpy.fft.rfft` → 提取主频、频带能量、谱质心、RMS、过零率 → 输出 `features.csv`。
2. `src/classify.py`：按工况分层留出盲测集（如每工况 12 组训练 / 3 组盲测），用简单阈值或 KNN 分类，输出混淆矩阵与准确率。
3. `noise_robustness.md`：对比 cond02 与 cond05 的特征漂移与准确率下降，写清加了什么滤波 / 换了哪个特征、效果如何。
4. `process_logs/blind_test.mp4`：横屏录制，画面同时包含设备、实时分类结果、本人操作；盲测样本在录前不参与调参。

## 过程留痕要求

- `process_logs/` 要有**跨多日**的记录，不要一天全部推完。
- 至少 **3 次有实际 diff 的 commit**，且每次能对应到日志里的发现，例如：
  - `iter01`：初版阈值在快跑/失衡间误判 → 改用谱质心
  - `iter02`：加背景噪声后准确率下降 → 增加带通滤波
  - `iter03`：修正手机距离不一致导致的两组离群数据
- 每次迭代在 `iterations/iterXX.md` 写清「看到了什么 → 改了什么 → 结果变化」。
- 被推翻的尝试保留，不要删。

## 与课题 08 的关系

课题 08 是预实验（手机传感器 → CSV → 阈值判别），本项目在其方法上加入频域特征与盲测验证。**两批原始数据、时间戳、照片完全独立，不复用同一批文件。**
