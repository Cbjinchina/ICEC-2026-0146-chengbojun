# 项目三：基于手机内置传感器的日常旋转机械 / 电器异常声振诊断仪

**材料**：个人手机（麦克风 + 加速度计）+ 电风扇 / 吹风机 + 胶带。不用借设备、不用焊接、不用连续多天挂机。

## 5 种工况定义（实际采集版）

| 编号 | 工况 | 具体做法 | 区分依据 |
|---|---|---|---|
| cond01 | 正常 · 1 档 | 风扇 1 档空载稳定运行 | 转速最低，基频与调制频率最低 |
| cond02 | 正常 · 4 档 | 风扇 4 档空载稳定运行 | 转速最高，谐波整体上移 |
| cond03 | 扇叶失衡 | 单片扇叶靠叶尖处贴硬纸板配重，**2 档**运行 | 一倍转频及其谐波幅值升高 |
| cond04 | 正常 · 2 档 | 风扇 2 档空载（**cond03 的同档位对照**） | 与 cond03 只差配重这一个变量 |
| cond05 | 进气受阻 | 纸板挡住**后网罩（进风面）约一半**，1 档运行 | 气动宽带噪声抬升、谱平坦度上升 |

> **为什么 cond03 从 4 档改成 2 档**：4 档转速高、机身抖动明显，配重块容易甩脱，且
> 高转速下风噪把失衡谐波盖住。改到 2 档后必须补一条 **2 档正常基线（cond04）**，
> 否则失衡特征会和"档位"混淆——这是单变量对照的要求，不是多余的一条。
>
> 原计划"叠加背景噪声"工况已取消：现场录背景噪声不可控且不可复现，
> 改为在 `src/add_noise.py` 里按目标 SNR **离线合成**白噪声，随机种子固定，
> 任何人可重跑复现，见 `noise_robustness.md`。

## 文件命名与采样约定

- 音频：`cond01_run01.wav` … `cond05_run15.wav`，共 **75 个**文件。
- 同步加速度（可选但加分）：同名 `.csv`，字段 `time_s, acc_x, acc_y, acc_z`。
- 每段连续录 **10 秒**；同一工况内手机位置、距离、朝向保持不变。
- 采样率、机型、麦克风距离、胶带位置等全部写进 `process_logs/raw/sampling_notes.md`。
- 实验照：每种工况至少 1 张，能看到设备、手机摆放、异常设置（如胶带/配重/遮挡）。

## 重录后如何只替换一个工况

现场条件变了要重录某一条时，**不要**把 5 条全部重跑（切片是按文件修改时间排工况的，整体重跑容易错位）。只替换的那一条用：

```bash
python src/patch_condition.py --input "新录音.m4a" --cond 3
```

它会按与 `ingest_audio.py` 完全相同的规则（首尾各裁 1 s、均分 15 段）重新切片，覆盖 `cond03_run01..15.wav`，旧文件留 `.bak` 备份，并打印每段 RMS/峰值、提示削波或电平过低。

- 原始录音统一归档在 `process_logs/raw_src/`，文件名带工况与时间（如 `c03_unbalance_1639.m4a`），保证任何人能从头重跑整条链路。

## 分析链路

1. `src/fft_features.py`：读 WAV → 分帧加 Hanning 窗 → **手写 radix-2 FFT**（不依赖 numpy）→ 提取主频、八度频带能量占比、谱质心、谱平坦度、谱峰显著性、峰值因子、包络调制深度 → 输出 `features.csv`。
2. `src/classify.py`：按工况分层留出盲测集（每工况最后 3 组不参与训练），标准化后用类中心最近邻判别，输出混淆矩阵与准确率。
   `--feature-set basic` 只用 6 项基础特征（消融对照，80.0%），`all` 用 19 项（**93.3%**）。
   特征列表写在报告头部，避免"以为加了特征、其实没进计算"的静默失效——这个坑踩过一次，见 `iterations/iter04.md`。
3. `noise_robustness.md`：对比 cond02 与 cond05 的特征漂移与准确率下降，写清加了什么滤波 / 换了哪个特征、效果如何。
4. `process_logs/blind_test.mp4`：横屏录制，画面同时包含设备、实时分类结果、本人操作；盲测样本在录前不参与调参。

## 过程留痕要求

- `process_logs/` 要有**跨多日**的记录，不要一天全部推完。
- 至少 **3 次有实际 diff 的 commit**，且每次能对应到日志里的发现，例如：
  - `iter01`：初版阈值在快跑/失衡间误判 → 改用谱质心
  - `iter02`：加背景噪声后准确率下降 → 增加带通滤波
  - `iter03`：修正手机距离不一致导致的两组离群数据
- 每次迭代在 `iterations/iterXX.md` 写清「看到了什么 → 改了什么 → 结果变化」。
- 被推翻的尝试保留，不要删。
